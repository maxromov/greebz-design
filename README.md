# GREEBZ Design

Єдина дизайн-система бренду. Звідси її беруть усі сайти GREEBZ: і B2C-магазин,
і B2B-сайт. Правимо тут, в одному місці.

## Що всередині

| Файл | Що це |
| --- | --- |
| `BRAND-KEY.md` | нормативний документ: колір, типографіка, форма, плашки, логотип, тон. Якщо код і цей файл розходяться, правий цей файл |
| `tokens.css` | машинні значення: змінні `--gz-*` і утиліти `.gz-h1`, `.gz-label`, `.gz-container`, `.gz-btn`, `.gz-pill` |
| `components.css` | компоненти, зняті з Figma: кнопки, поля, вкладки, пагінація, посилання, соцмережі. Підключається окремо |
| `fonts.css` | `@font-face` для Onest і Martian Mono |
| `fonts/*.woff2` | самі шрифти, канонічні копії |
| `logo/logo.svg`, `logo/mark.svg` | логотип і знак |
| `icons/brand/` | 14 брендових піктограм зі стор. 38 брендбука, кожна в трьох варіантах (див. «Іконки») |
| `icons/ui/` | 42 інтерфейсні іконки з кадру `Icon` у Figma, 24×24, `currentColor` |
| `shapes.svg` | фірмова форма, 9 готових спрайтом |
| `shape.js` | генератор фірмової форми: будує SVG-шлях з оптичною компенсацією радіусів під реальний розмір блока |
| `brandbook/Brandbook.pdf` | джерело норми, 76 сторінок. У пакет не потрапляє |
| `brandbook/logo-print/` | логотипи для друку й партнерів, powered-by. У пакет не потрапляє |

Джерела: брендбук `Brandbook.pdf` (Make Sense, 2025) і Figma
`6nkDvtUkBzaOalaQ1q7bmJ`, сторінка Design. Брендбук дає інваріанти бренду,
Figma дає веб-шар. Де вони розходяться, рішення записане в `BRAND-KEY.md`.

## Як підключити на сайті

```
npm i github:maxromov/greebz-design#v1.0.0
```

Репозиторій публічний, тому ані токена, ані реєстру не треба: Vercel ставить
пакет сам. Версію закріплюємо тегом, і правка тут не ламає сайт: він перейде
на нову версію тоді, коли ви зміните тег у `package.json`.

У головному css сайту:

```css
@import "@maxromov/greebz-design/tokens.css";
@import "@maxromov/greebz-design/fonts.css";
```

**Шрифти.** `fonts.css` посилається на `/fonts/*.woff2`, бо сайти
передзавантажують їх через `<link rel="preload">` з абсолютним шляхом.
Тому чотири файли з `fonts/` треба один раз покласти в `public/fonts/` сайту.
Шрифти не змінюються, тож це разова дія.

## Що сюди належить, а що ні

Сюди: усе, що однакове для будь-якого сайту GREEBZ. Палітра, шкала, відступи,
радіуси, кнопки, поля, картки, логотип, форма.

Не сюди: ритм секцій конкретного сайту, його блоки, екрани, контент. Магазин
і B2B-сайт розкладаються по-різному, і це нормально.

## Версії

Кожен сайт закріплює свою версію. Правка тут не ламає сайт: сайт підтягує
нову версію тоді, коли ви цього захочете, одним рядком у `package.json`.

Реліз: підняти `version`, закомітити, поставити тег, `npm publish`.

## Компоненти

`components.css` підключається окремо від `tokens.css` і нічого в ньому не
перевизначає:

```css
@import "@maxromov/greebz-design/tokens.css";
@import "@maxromov/greebz-design/components.css";
```

| Клас | Що це | Модифікатори |
| --- | --- | --- |
| `.gz-button` | кнопка 45px | `--fill`, `--stroke`, `--dark`, `--sm` (40px) |
| `.gz-icon-btn` | квадратна кнопка з іконкою, 56px | `--stroke`, `--md` (40), `--sm` (32) |
| `.gz-control` | контурна керівна кнопка, 51px | `--md` (40) |
| `.gz-qty` | лічильник кількості, 28px | , |
| `.gz-tab` | вкладка 45px | `--sm` (37), `--active` або `aria-selected` |
| `.gz-page` | клітинка пагінації, 51px | `--md` (40), `--more` |
| `.gz-input` | поле й `textarea.gz-input` | `--on-accent` для світлої плити |
| `.gz-input-error` | текст помилки під полем | `--on-accent` |
| `.gz-link`, `.gz-nav-link` | посилання й пункт меню | `--on-accent`, `--current` |
| `.gz-social` | кнопка соцмережі, 45px | `--sm` (32), `--on-accent` |

Стани вимкнення читаються з `disabled` або `aria-disabled="true"`, активний
пункт , з `aria-current` чи `aria-selected`. Фокус обведено таном на всіх.

Дві свідомі відмінності від макета записані в шапці файлу: бордери не тонші
за 1px, а мобільні розміри зроблено модифікаторами, а не медіазапитами.

У `tokens.css` лишаються старіші наближення `.gz-btn`, `.gz-chip`, `.gz-pill`:
на них стоїть greebz.shop. Вони не конфліктують з новим шаром, але колись
сайт треба перевести на `.gz-button` і прибрати дублювання.

## Іконки

`icons/brand/` , 14 піктограм зі стор. 38 брендбука, витягнуті з PDF як вектор і
приведені до токенів кольору. Імена: `dumbbell`, `bolt`, `brain`, `meditation`,
`chevrons-forward`, `heart`, `shield`, `molecule`, `g-mark`, `walk`, `chevrons-back`,
`flame`, `sun`, `bacteria`. Лист для ока: `icons/brand-sheet.png`.

Три варіанти на кожну, як у BRAND-KEY §8:

| Файл | Що це | Де доречно |
| --- | --- | --- |
| `<назва>.svg` | контейнер фірмового кольору, гліф вирізано наскрізь | на чорному: гліф читається чорним, на будь-якому іншому тлі , кольором тла |
| `<назва>-inverse.svg` | чорний контейнер, кольоровий гліф | на полотні `#191919` і на світлих плитах |
| `<назва>-glyph.svg` | лише гліф, `fill="currentColor"` | у тексті, кнопках, списках; колір задає CSS |

Кольори контейнерів закріплені за піктограмами так, як на стор. 38, і не
змінюються: це частина впізнаваності набору.
