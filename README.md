# GREEBZ Design

Єдина дизайн-система бренду. Звідси її беруть усі сайти GREEBZ: і B2C-магазин,
і B2B-сайт. Правимо тут, в одному місці.

## Що всередині

| Файл | Що це |
| --- | --- |
| `BRAND-KEY.md` | нормативний документ: колір, типографіка, форма, плашки, логотип, тон. Якщо код і цей файл розходяться, правий цей файл |
| `tokens.css` | машинні значення: змінні `--gz-*` і утиліти `.gz-h1`, `.gz-label`, `.gz-container`, `.gz-btn`, `.gz-pill` |
| `fonts.css` | `@font-face` для Onest і Martian Mono |
| `fonts/*.woff2` | самі шрифти, канонічні копії |
| `logo/logo.svg`, `logo/mark.svg` | логотип і знак |
| `shapes.svg` | фірмова форма |

Джерела: брендбук `Brandbook.pdf` (Make Sense, 2025) і Figma
`6nkDvtUkBzaOalaQ1q7bmJ`, сторінка Design. Брендбук дає інваріанти бренду,
Figma дає веб-шар. Де вони розходяться, рішення записане в `BRAND-KEY.md`.

## Як підключити на сайті

```
npm i @maxromov/greebz-design
```

У головному css сайту:

```css
@import "@maxromov/greebz-design/tokens.css";
@import "@maxromov/greebz-design/fonts.css";
```

**Шрифти.** `fonts.css` посилається на `/fonts/*.woff2`, бо сайти
передзавантажують їх через `<link rel="preload">` з абсолютним шляхом.
Тому чотири файли з `fonts/` треба один раз покласти в `public/fonts/` сайту.
Шрифти не змінюються, тож це разова дія.

## Що сюди належить, а що ні

Сюди: усе, що однакове для будь-якого сайту GREEBZ. Палітра, шкала, відступи,
радіуси, кнопки, поля, картки, логотип, форма.

Не сюди: ритм секцій конкретного сайту, його блоки, екрани, контент. Магазин
і B2B-сайт розкладаються по-різному, і це нормально.

## Версії

Кожен сайт закріплює свою версію. Правка тут не ламає сайт: сайт підтягує
нову версію тоді, коли ви цього захочете, одним рядком у `package.json`.

Реліз: підняти `version`, закомітити, поставити тег, `npm publish`.
