# Логотип и знак

Оригиналы - из папки бренда `GREEBZ_logotypes_and_mark` и `Powered by Greebz` на Google Drive
(Make Sense agency, 2025). Не перерисовывать и не набирать шрифтом: слово GREEBZ в Onest
логотипом не является.

| Файл | Что это | Как использовать |
|---|---|---|
| `logo.svg` | Логотип, `fill="currentColor"`, viewBox 1920×482.63 | Инлайн в HTML, цвет задаёт CSS. Хедер, футер |
| `mark.svg` | Знак G, `currentColor`, viewBox 1080×1413.87 | Favicon, аватар, watermark карточки. Не рядом с логотипом |
| `powered-by.svg` | Стикер «Powered by GREEBZ» в рамке, `currentColor` | Блок партнёров и B2B. Допустим поворот |
| `logo-white.svg`, `mark-white.svg`, `powered-by-white.svg`, `powered-by-black.svg` | Оригиналы как есть | Для передачи партнёрам и в печать |

Правила (BRAND-KEY §7): основной вариант белый на чёрном; свободное поле = высота H со всех
сторон; минимум 20px по высоте; знак и логотип не ставить в одной плоскости; не поворачивать
(кроме стикера), не искажать, без цвета, контура, теней и градиентов.
